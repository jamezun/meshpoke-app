# Seed Data Sources

## districts.geojson
- **Geometry:** https://github.com/southparkstan123/hong-kong-geojson (`hong-kong.json`, 18 districts).
  Upstream repo does not state a licence; boundaries appear derived from OpenStreetMap /
  HK government open data. Treat as CC-BY-compatible for prototyping; before commercial
  launch, replace with the official CSDI "District Boundaries" dataset
  (https://portal.csdi.gov.hk/) under the Open Data Licence — geometry swap only, same schema.
- **Chinese names (name_zh):** standard 18-district names added by MeshPoke (public fact, no licence issue).
- **Normalisation performed:** Polygon/GeometryCollection → MultiPolygon; properties reduced
  to `{name_en, name_zh}`.

## Founding counters / city rooms / admin user
- Generated by `apps/api/src/db/seed.ts` — no external data.
